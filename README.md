# Программное обеспечение для микроконтроллера Arduino, координирующего работу домашней роторной гидропонной системы
Проект был выполнен в рамках вкр

### Введение в предметную область
**Гидропоника** – это метод выращивания растений без почвы (на искусственных средах) с использованием питательных растворов.\
На сегодняшний день существует несколько видов гидропонных систем. Одним из них является **система периодического затопления**, в которой корни растений периодически заливаются питательным 
раствором, который затем сливается.\
**Роторная гидропоника** представляет из себя особый подход к системе периодического затопления. В основе конструкции лежит вращающийся вокруг источника света ротор, посадочная площадь располагается на его внутренней цилиндрической поверхности. Данная конструкция позволяет уменьшить площадь под установку, сохраняя при этом посадочную площадь, а также снизить потребление электроэнергии.

### Функциональные требования: 
* обеспечение медленного вращения ротора; 
* уведомление пользователя о низком уровне воды; 
* вывод значения концентрации удобрений в воде и температуры воды 
* на дисплей; 
* уведомление пользователя о концентрации удобрений, не 
* соответствующей норме; 
* поддержание температуры в пределах нормы; 
* обеспечение циклического режима работы лампы; 
* изменение режима работы лампы.

### Выбор среды разработки и компонентов
В качестве среды разработки использовалась онлайн-платформа Tinkercad 
Circuits  со встроенным симулятором.\
Для исполнения кода программы был выбран микроконтроллер Arduino 
UNO.


Также были выбраны компоненты, на которых впоследствии проводилось 
тестирование разработанного программного обеспечения:
* Для реализации вывода информации для пользователя был выбран LCD дисплей с модулем I2C, так как данный модуль позволяет уменьшить количество используемых пинов. Для работы с I2C были подключены библиотеки Wire.h и LiquidCrystal_I2C.h.
* Для реализации ротора был выбран двигатель постоянного тока и драйвер L293D, необходимый для управления мотором.
* Так как симулятор ограничен в выборе компонентов и в выбранной среде разработки отсутствуют датчики уровня воды и концентрации соли, то в качестве их замены были выбраны потенциометры. Для уведомления пользователя об изменениях показателей датчиков использовались цветные светодиоды.
* Для реализации измерения температуры был подключен датчик температуры TMP36, так как выбранная среда разработки позволяет изменять его показания. Как было сказано ранее набор компонентов ограничен, из-за чего вентилятор был заменен на двигатель постоянного тока, а нагреватель – на лампу. Несмотря на то, что выбранные компоненты не реализуют требующийся функционал, они наглядно демонстрируют работу модуля контроля температуры воды.
* Для реализации искусственного освещения была подключена лампа, а для переключения режимов ее работы – ползунковый переключатель.
