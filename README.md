# Программное обеспечение для микроконтроллера Arduino, координирующего работу домашней роторной гидропонной системы
Проект был выполнен в рамках вкр

### Введение в предметную область
**Гидропоника** – это метод выращивания растений без почвы (на искусственных средах) с использованием питательных растворов.\
На сегодняшний день существует несколько видов гидропонных систем. Одним из них является **система периодического затопления**, в которой корни растений периодически заливаются питательным 
раствором, который затем сливается.\
**Роторная гидропоника** представляет из себя особый подход к системе периодического затопления. В основе конструкции лежит вращающийся вокруг источника света ротор, посадочная площадь располагается на его внутренней цилиндрической поверхности. Данная конструкция позволяет уменьшить площадь под установку, сохраняя при этом посадочную площадь, а также снизить потребление электроэнергии.

### Функциональные требования: 
* обеспечение медленного вращения ротора; 
* уведомление пользователя о низком уровне воды; 
* вывод значения концентрации удобрений в воде и температуры воды 
* на дисплей; 
* уведомление пользователя о концентрации удобрений, не 
* соответствующей норме; 
* поддержание температуры в пределах нормы; 
* обеспечение циклического режима работы лампы; 
* изменение режима работы лампы.

### Выбор среды разработки и компонентов
В качестве среды разработки использовалась онлайн-платформа Tinkercad Circuits  со встроенным симулятором.\
Для исполнения кода программы был выбран микроконтроллер Arduino UNO.


Также были выбраны компоненты, на которых впоследствии проводилось тестирование разработанного программного обеспечения:
* Для реализации вывода информации для пользователя был выбран LCD дисплей с модулем I2C, так как данный модуль позволяет уменьшить количество используемых пинов. Для работы с I2C были подключены библиотеки Wire.h и LiquidCrystal_I2C.h.
* Для реализации ротора был выбран двигатель постоянного тока и драйвер L293D, необходимый для управления мотором.
* Так как симулятор ограничен в выборе компонентов и в выбранной среде разработки отсутствуют датчики уровня воды и концентрации соли, то в качестве их замены были выбраны потенциометры. Для уведомления пользователя об изменениях показателей датчиков использовались цветные светодиоды.
* Для реализации измерения температуры был подключен датчик температуры TMP36, так как выбранная среда разработки позволяет изменять его показания. Как было сказано ранее набор компонентов ограничен, из-за чего вентилятор был заменен на двигатель постоянного тока, а нагреватель – на лампу. Несмотря на то, что выбранные компоненты не реализуют требующийся функционал, они наглядно демонстрируют работу модуля контроля температуры воды.
* Для реализации искусственного освещения была подключена лампа, а для переключения режимов ее работы – ползунковый переключатель.

### Реализация и демонстрация
#### Модуль управления ротором
Данный модуль реализуется с помощью функции `motorManage` и отвечает за поддержание непрерывного вращения мотора с постоянной скоростью, что осуществляется за счет передачи значения скорости на пин `MOTOR_EN`. Скорость вращения определяется в диапазоне от 0 до 255, где 0 означает, что мотор выключен, 255 – скорость максимальна. Так как требуется медленное вращение, было установлено значение 1. Для работы мотора также необходимо задать направление вращения. Это осуществляется с помощью подачи напряжения на один из входных пинов драйвера мотора.

#### Модуль отслеживания уровня воды
Модуль отслеживания уровня воды состоит из двух компонентов: датчика уровня воды и светодиода. Принцип работы датчика заключается в изменении проводимости между его пластинами в зависимости от уровня воды: чем выше поднимается уровень воды, тем выше напряжение на выходе датчика.\
Микроконтроллер считывает напряжение с датчика и преобразует его в число от 0 до 1023. Если полученное значение меньше установленной границы в 500, то загорается синий светодиод, тем самым оповещая пользователя о необходимости долить воду (см. `waterLevelTracking`). При повышении уровня воды светодиод выключается.

#### Модули отслеживания уровня удобрений в воде и вывода информации
Данный модуль состоит из датчика концентрации солей и двух светодиодов. Датчик измеряет содержание в воде проводящих веществ, таких как взвешенные вещества, тяжелые металлы и проводящие ионы, и передает напряжение на микроконтроллер. Он преобразует входное напряжение от 0 до 5 вольт в числовое значение от 0 до 1023. Полученное значение было преобразовано обратно в напряжение, которое затем было переведено в количество растворенных в воде примесей (TDS) (см. `saltMonitoring`).\
Уведомление пользователя о текущем значении концентрации солей происходит с помощью вывода данных на дисплей. Если значение TDS ниже нормы, то загорается желтый светодиод, если выше – красный, при этом на дисплей выводится соответствующее сообщение.


На рисунках показана работа модулей отслеживания уровня удобрений в воде и вывода информации. На дисплей выводится значение концентрации солей (TDS) в ppm (количество частиц солей на 1 миллион частиц воды). При концентрации солей ниже и выше нормы загорается соответствующий светодиод и на дисплей выводится сообщение о необходимости корректировки количества удобрений.

#### Модуль контроля температуры воды
Данный модуль состоит из датчика температуры, вентилятора и нагревателя. Датчик измеряет температуру и передает соответствующее ей напряжение на микроконтроллер. Полученное значение переводится обратно в значение температуры в градусах Цельсия. Затем температура проверяется на соответствие норме: если значение выше 25&deg;C или ниже 16&deg;C, включается вентилятор или нагреватель соответственно (см. `termControl`). Таким образом система поддерживает температуру воды в диапазоне благоприятном для корней растений. Текущее значение температуры выводится на дисплей.


На рисунках показана работа модуля контроля температуры воды. При температуре ниже или выше нормы включается нагреватель (крайняя правая лампа) или вентилятор (левый двигатель) соответственно.

#### Модуль переключения режимов работы лампы и модуль работы режима лампы 
Настройка режимов работ лампы осуществляется за счет установки 
периодов, когда лампа включена и выключена (см. листинг). Для простоты 
тестирования значения заданы в миллисекундах.
```
const unsigned int onTimeMode1 = 2000; // время в мс когда лампа включена (режим 1)
const unsigned int offTimeMode1 = 2000; // время в мс когда лампа выключена (режим 1)
const unsigned int onTimeMode2 = 5000; // время в мс когда лампа включена (режим 2)
const unsigned int offTimeMode2 = 1000; // время в мс когда лампа выключена (режим 2)
```
Модуль переключения режимов работы лампы считывает состояние переключателя и передает значения определенных ранее констант, соответствующие выбранному режиму, в функцию `lampStart` (см. `lampManage`), которая реализует логику работы режима лампы.


Модуль работы режима лампы отвечает за включение и выключение лампы через определенные периоды времени. После запуска программы лампа включается и время включения лампы сохраняется в переменную lampStartTime. Когда значение времени, прошедшего с момента включения лампы (переменная pastTime), достигает значения постоянной, обозначающей период работы лампы, лампа выключается и точка отсчета обновляется (см. `lampStart`).
